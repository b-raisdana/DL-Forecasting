# Weakness Analysis

Register of design gaps across [01](01-Objective.md)–[04](04-Experimentation, Evaluation & Optimization.md): topics missing/weak, and techniques/alternatives never listed for comparison. Companion to [00-ToC & Coverage.md](00-ToC & Coverage.md) (topic-level gaps) — this doc adds importance ratings and technique-level gaps 00-ToC doesn't score.

**Importance:** 1 = risks invalidating conclusions if unaddressed (leakage, overfitting, undefined backtest mechanics) · 2 = real blind spot, likely changes results/decisions · 3 = polish, low risk if deferred.
