# Weakness Analysis

Register of every open design gap across [01](01-Objective.md)–[04](04-Experimentation, Evaluation & Optimization.md) — topics missing/weak, and techniques/alternatives never listed for comparison — each importance-rated. [00-ToC & Coverage.md](<00-ToC & Coverage.md>) lists only what's covered elsewhere; if a topic isn't there, it's here or in [99-Exclusion.md](99-Exclusion.md).

**Importance:** 1 = risks invalidating conclusions if unaddressed (leakage, overfitting, undefined backtest mechanics) · 2 = real blind spot, likely changes results/decisions · 3 = polish, low risk if deferred.
